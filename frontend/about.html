ABOUT THE PROJECT

Turning Data Into Customer Intelligence.

ChurnAI is a machine learning application designed to estimate whether a telecom customer is likely to churn.

01

The Problem

Customer churn can significantly affect telecom businesses. Identifying customers who may leave allows businesses to take proactive retention actions.

02

The Solution

ChurnAI analyzes customer behavior, usage, recharge activity and other engineered features using a trained machine learning model.

03

The Technology

The application combines Python, scikit-learn, Logistic Regression, FastAPI, HTML, CSS and JavaScript.
